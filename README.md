# 불씨 — 김시언 포트폴리오

기획 · 마케팅 · 콘텐츠 포트폴리오 사이트입니다.
표지는 스크롤에 따라 작은 불꽃 → 커지는 불 → 번지는 불로 이어지고, 화면이 타들어 가며 밝은 포트폴리오가 열립니다.

- 사이트: https://happybluebird.github.io/bulssi-portfolio/
- 첫 장면의 3D 불씨: [thrine.app](https://thrine.app) 임베드 (불러오지 못하면 이미지 불꽃으로 대체)
- 불 장면: three.js 셰이더 (WebGL을 쓸 수 없으면 이미지 전환으로 대체)
- 서체: Pretendard (SIL OFL 1.1)
